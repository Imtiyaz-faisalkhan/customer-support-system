# Support Knowledge Base

## Refunds

- Full refund if requested within 30 days of purchase, processed in 5–7 business days.
- Partial refund may apply if product was used for more than 7 days (reviewed case-by-case).
- Customer must provide order ID or registered email to process any refund.

## Technical Issues

- Login problems: use Forgot Password first, then try clearing cache or switching browsers.
- Missing emails: check spam folder; if not found, we can resend manually.
- Slowness or performance issues: disable browser extensions or switch browsers. Ask for device and browser version if unresolved.

## App Crashes

- Standard fix: force close, update app, restart device.
- Blank/stuck screen: check internet and relaunch.
- If crash persists after reinstall, collect device model and OS version for escalation.
